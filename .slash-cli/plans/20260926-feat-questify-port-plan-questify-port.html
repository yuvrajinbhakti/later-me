Questify core-loop port — implementation plan

Rebuild Later Me's UI as Questify's core loop on real on-device data, and extend the native watcher to match. Spec: .slash-cli/specs/2026-09-26-questify-port-design.md.

For agentic workers: REQUIRED SUB-SKILL: use subagent-driven-development or executing-plans to implement task by task. Each task's implementation goes through test-driven-development. Steps use checkbox syntax.

Goal: Later Me looks and behaves like Questify's core loop (13 screens, 3 tabs) with every number real and persisted, and the watcher honours sarcasm level, alert-after and daily limit.

Architecture: Pure TypeScript domain modules (quests, ETA, roasts, usage aggregation, migration) carry all logic and are unit-tested with Jest. A small React context store persists AppState to AsyncStorage and pushes a derived config plus roast pools to the native module. Expo Router renders thin screens over a Questify design layer. The Kotlin module gains a pure TriggerPolicy (JUnit-tested), a raw usage-events query, notification delivery and a restyled overlay.

Tech stack: Expo SDK 57, React Native 0.86, Expo Router, react-native-svg, @expo-google-fonts/inter, @react-native-community/datetimepicker, AsyncStorage 2.2, Jest via jest-expo, Kotlin + JUnit 4 for the module.

Global constraints

  • App name stays Later Me, package com.yuvraj.laterme. Questify is the design source only.
  • Dark theme only. Questify dark tokens verbatim: bg #0B0D12, surface #131720, elevated #1A1F2B, border #292F3D, text #F5F7FA, text-2 #9AA3B2, muted #656D7B, accent #8B7CFF, mint #5EE7B7, warning #FFCC66, danger #FF6B81, sarcasm #FF7A59.
  • Violet marks only current position and next action; orange only where the user's own usage earned it; at most two accents per screen.
  • Tabs: Home · Quests · Attention.
  • Sarcasm level: gentle = notification; normal = overlay; savage = overlay, harsher copy, faster escalation.
  • Alert after: 5 / 10 / 15 / 30 min (dev builds add a 30-second option for testing). Daily limit: 1h / 2h / 3h / none.
  • Escalation wait (fixed): 2 min gentle and normal, 1 min savage.
  • Daily limit fires one callout per day, delivered per the current level.
  • Roast copy describes behaviour, never character. Banned: lazy, pathetic, loser, decoration, wasted potential, useless, failure, shame.
  • When the focus quest is paused / completed / deleted, the most recently created remaining active quest becomes focus; else none.
  • Commits: plain messages, no co-author or generated-by trailers. Commit, never push.
  • Before writing Expo code, consult the SDK 57 docs (repo AGENTS.md rule).
